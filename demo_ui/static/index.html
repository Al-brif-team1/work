Decision layer

Но анализ — ещё не решение.

Полнота, соответствие и риски дают разные сигналы. Их нужно собрать в одно итоговое решение.

Arbiter

Как система принимает решение?

Сигналы говорят о разных сторонах проекта. Нужен один итоговый класс.

Информации достаточно Блокирующих пробелов нет blocking_missing_count = 0
Соответствие Есть YELLOW-сигнал traffic_light = yellow
Риск Объём проекта слишком большой scope_too_large
Дополнительные уточнения Есть некритичный вопрос optional_missing_count = 1
